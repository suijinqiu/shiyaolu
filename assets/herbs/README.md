# 药材图片目录

## 现在为什么是空的

站内目前**没有放任何药材照片**，这不是没做完，是刻意的：

- 药材识别的错误代价极高。**配错一张图的后果，比没有图严重得多**——尤其是附子、半夏、三七这类有毒或有毒伪品的药材，一张"看着像"的图会直接诱导误用。
- 网上能随手搜到的中药材图，绝大多数来源不明、授权不清，且相当一部分本身就标错了物种（例如把菊三七当三七）。
- 我是程序，无法逐张核验"这张图确实是这个物种、这个部位、这个炮制品"。**没法核验的图，宁可不放。**

所以详情页显示的是占位说明，而不是一张不确定的图。

## 怎么加图（推荐流程）

1. 取得**可核实来源**的图片，优先顺序：
   - 自己拍摄（最优，附拍摄说明）
   - 《中国药典》官方图谱 / 省级药检所公开图谱
   - 明确标注 CC BY / CC BY-SA / 公有领域的图库（需保留署名与协议）
2. 每张图确认三件事：**物种正确、部位正确、炮制状态正确**（生品与制品外观差异很大）。
3. 按药材 `id` 命名，放进本目录：

```
assets/herbs/renshen.jpg      人参
assets/herbs/fuzi.jpg         附子
assets/herbs/sanqi.jpg        三七
```

支持的扩展名以 `app.js` 里的约定为准：当前写死为 `<id>.jpg`。要换格式，把
`app.js` 中 `h.image = 'assets/herbs/' + h.id + '.jpg';` 改成对应后缀即可。

4. 图片放好后**刷新页面即生效**，无需改数据、无需构建。加载失败会自动回落到占位说明。

## 建议的图片规格

| 项 | 建议 |
| --- | --- |
| 内容 | 药材单体近景，浅色背景，能看清断面 |
| 尺寸 | 长边 800–1200 px |
| 体积 | 单张 ≤ 200 KB（JPEG q80） |
| 构图 | 与 `identify` 字段描述的特征对应（如断面、环纹、油点） |

## 署名与协议

若使用第三方图片，请在本文件下方登记，并在页面 `figcaption` 中体现来源。
当前实现会在加载成功时把来源写成 `图片来自 assets/herbs/<id>.jpg`，可在
`app.js` 的 `renderFigure()` 中替换为带署名的文案。
